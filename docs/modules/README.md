# Module Guides

- [Perceive](perceive.md) - Problem analysis and uncertainty identification
- [Reason](reason.md) - Step-by-step problem solving
- [Verify](verify.md) - Solution checking and error correction

Additional layers:
- DISCUSS - Multi-agent debate (in `imra.core.layers`)
- RESOLVE - Forced resolution after debate (in `imra.core.layers`)
- GESTALT - Coherence analysis (in `imra.core.gestalt`)

See `src/imra/core/` for implementation details.
